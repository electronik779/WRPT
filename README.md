----
Программа предназначена для выработки у студентов навыка построения противоперебойной линии диспетчерского графика при многолетнем регулировании стока.
Программа обеспечивает выполнение расчетов на основе решения уравнения водного баланса для многолетнего регулирования. Цикл сработки и наполнения сезонной составляющей объема водохранилища равен одному году. 

Программа WRPT осуществляет расчеты для заданного диспетчерского графика. Поскольку оптимальный вид диспетчерского графика для данных условий заранее неизвестен, то расчеты приходится повторять по нескольку раз: для предварительно принимаемого диспетчерского графика и после его коррекции. Последовательная коррекция диспетчерского графика для каждого календарного месяца требует выполнения нескольких последовательных расчетов.

# Установка

## Windows

Для Windows x64 скачайте "свежий" (Latest) релиз [Setup_WRPT_vXXXX.X_Win.exe](https://github.com/electronik779/WRPT/releases) и установите, выбрав опцию "для всех пользователей".

>[!NOTE]
>Для работы программы требуются установленные на компьютере пакеты .NET SDK 10 и App SDK (версией 1.8).
>При отсутствии этих пакетов программа установки предложит скачать их и установить.
>
>В случае каких либо ошибок необходимо самостоятельно скачать и установить [.NET SDK 10](https://dotnet.microsoft.com/ru-ru/download/dotnet/10.0) и [App SDK](https://learn.microsoft.com/ru-ru/windows/apps/windows-app-sdk/downloads-archive) (проверено с версией 1.8.10).
>После их установки рекомендуется перезагрузить компьютер.

## MacOS

Для MacOS скачайте "свежий" (Latest) релиз [Setup_WRPT_vXXXX.X_Mac.dmg](https://github.com/electronik779/WRPT/releases) и установите.

>[!NOTE]
>Возможность установки и работоспособность не проверялись.

# Описание интерфейса ввода

<img width="786" height="1132" alt="image" src="https://github.com/user-attachments/assets/516917c9-c2f3-46ed-81bf-9a90f292d8ef" />

>[!NOTE]
>Окно программы имеет вертикальную прокрутку.
>Все таблицы, размер которых не помещается в окно программы, имеют индивидуальную прокрутку.

**`Номер календарного месяца начала расчета`** - порядковый номер месяца, с которого начинается расчет.

>[!NOTE]
>Расчет может начинаться с любого месяца.

>[!TIP]
>Можно начинать расчет с полностью заполненного водохранилища, тогда начальное заполнение полезного объема будет равно полезному объему.

**`Количество значений притока`** - количество значений среднемесячных расходов бытового стока.

Для ввода значений бытового стока необходимо создать таблицу. Нажмите кнопку `Создать` справа от поля ввода. Появится таблица под заголовком "Бытовой сток:", в которую необходимо ввести значения бытового стока в м³/с.

>[!NOTE]
>При нажатии кнопки `Создать` количество значений притока проверяется на кратность двенадцати. При количестве значений не кратном году, количество увеличивается в большую сторону до ближайшего кратного значения.
>Максимальное количество значений - 600.

**`Полезный объем водохранилища, млн.м³`** - полезный объем водохранилища в млн.м³.

**`Мертвый объем водохранилища, млн.м³`** - мертвый объем водохранилища в млн.м³.

**`Объем, выделенный для многолетнего регулирования, млн.м³`** - объем, выделенный для многолетнего регулирования в млн.м³.

>[!TIP]
>Предварительно можно принять от 1/3 до 1/2 полезного объема

**`Начальное заполнение полезного объема, млн.м³`** - начальное заполнение полезного объема в млн.м³.

>[!NOTE]
>Объем в водохранилище соответствующий номеру календарного месяца начала расчета.

>[!TIP]
>Можно начинать расчет с полностью заполненного водохранилища, тогда начальное заполнение полезного объема будет равно полезному объему.

**`Количество точек характеристики верхнего бьефа`** количество точек аппроксимации зависимости уровня верхнего бьефа от объема воды в водохранилище.

Для ввода значений необходимо создать таблицу. Нажмите кнопку `Создать` справа от поля ввода. Появится таблица под заголовком "Характеристика верхнего бьефа:", в которую необходимо ввести значения объемов и соответствующие им отметки.

>[!TIP]
>- Рекомендуется задавать не менее пяти точек аппроксимации.
>- Значения объемов необходимо вводить в возрастающем порядке.
>- Т.к. кривая аппроксимируется линейной интерполяцией, то на криволинейных участках нужно выбирать больше точек.
>- Зависимость нужно начинать от дна водохранилища.

>[!NOTE]
>Максимальное количество значений - 20.

В таблицу "Диспетчерские остатки на конец месяца:" необходимо ввести значения диспетчерских остатков (объемов) в млн.м³.

>[!CAUTION]
>Значения диспетчерских остатков вводятся начиная с календарного месяца начала расчета.

>[!NOTE]
>Реализуется цикличное регулирование в течении ряда лет.

<img width="786" height="1131" alt="image" src="https://github.com/user-attachments/assets/9928926e-e084-49e1-bf76-3d032c88a0ff" />

В таблицу "Гарантированные расходы ГЭС:" необходимо ввести значения гарантированных расходов в м³/с.

>[!NOTE]
>Можно иметь два значения гарантированного расхода в течении года, например повышенное на паводковый период и пониженное на остальной.
>
>Гарантированный расход определяется по обеспеченной мощности и минимальному напору:
>
>$$Q_{гар}=\frac{N_{об}}{9,81 H_{т}^{мин} \eta_т \eta_г},\quad \mathnormal{м³/с},$$
>
>где $N_{об}$ - обеспеченная мощность ГЭС, кВт; $H_{т}^{мин}$ - минимальный напор, м; $\eta_т$ - кпд турбины; $\eta_г$ - кпд генератора.

В таблицу "Отбор из водохранилища:" необходимо ввести значения среднемесячных отборов воды из водохранилища в м³/с.

>[!NOTE]
>Предварительно можно задать равными нулю.

>[!TIP]
>В отборы следует включать потери на фильтрацию, испарение, льдообразование и потребление на различные нужды.

**`Количество точек характеристики нижнего бьефа`** количество точек аппроксимации зависимости уровня нижнего бьефа от расхода воды поступающего в него.

Для ввода значений необходимо создать таблицу. Нажмите кнопку `Создать` справа от поля ввода. Появится таблица под заголовком "Характеристика нижнего бьефа:", в которую необходимо ввести значения расходов и соответствующие им отметки.

>[!TIP]
>- Рекомендуется задавать не менее пяти точек аппроксимации.
>- Значения расходов необходимо вводить в возрастающем порядке.
>- Т.к. кривая аппроксимируется линейной интерполяцией, то на криволинейных участках нужно выбирать больше точек.
>- Зависимость нужно начинать от нуля расхода.

>[!NOTE]
>Максимальное количество значений - 20.

**`Схема питания ГЭС`** - индивидуальная или групповая схема питания ГЭС.

Индивидуальная схема питания применяется с русловыми и приплотинными ГЭС, когда вода к турбине подводится индивидуальными водоводами.\
Групповая - с деривационными, когда вода к турбине подводится водоводами с развилкой.\
От схемы питания зависит способ учета потерь напора.

**`Полный (максимальный) расход ГЭС, м³/с`** - максимальный расход всех турбин ГЭС в м³/с.

**`Потери напора, м`** - потери напора в водоводах при расчетном расходе в метрах.

**`Коэффициент потерь при Qгэс²`** - коэффициент потерь $k$ при $Q^2$.
>[!NOTE]
>$H_W=kQ^2$

>[!IMPORTANT]
>`Потери напора, м` - отображается при выборе индивидуальной схемы питания;\
>`Коэффициент потерь при Qгэс²` - отображается при выборе групповой схемы питания.

**`Кпд агрегата`** - средневзвешенный кпд гидроагрегата.

**`Номер контрольного месяца`** - номер контрольного месяца, как правило принимается самый маловодный месяц.

## Вкладка "Приток"
<img width="962" height="612" alt="image" src="https://github.com/user-attachments/assets/9ff5b03e-2fa9-49a6-9086-9c4b6a89775b" />

**На вкладке вводятся значения среднемесячного бытового стока (притока).**

>[!IMPORTANT]

## Вкладка "Гарантированные расходы"
<img width="962" height="612" alt="image" src="https://github.com/user-attachments/assets/0de07bf7-9721-4dcf-9b1a-d8877575d2b9" />

**На вкладке вводятся значения среднемесячных гарантированных расходов.**

В общем случае в течение года можно иметь два значения расхода - в зимние месяцы одно и другое в остальные. Могут быть индивидуальные значения для каждого месяца.

>[!TIP]
>Для начала можно принять одно значение во всех месяцах - гарантированный расход ГЭС.
>Определяется по обеспеченной мощности (90-95 % обеспеченности) и минимальному напору декабря:
>
>$Q_{гар}=\frac{N_{об}}{9,81 H_{т}^{дек} \eta_т \eta_г},\quad \mathnormal{м³/с},$
>
>где $N_{об}$ - обеспеченная мощность ГЭС, кВт; $H_{т}^{дек}$ - минимальный напор декабря, м; $\eta_т$ - кпд турбины; $\eta_г$ - кпд генератора.

# Отображение результатов расчета

Результаты расчета выводятся в отдельном окне, которое содержит одну кнопку и три вкладки

## Кнопка
![image](https://github.com/user-attachments/assets/352a83bf-d771-4548-b32d-87278daa6ece) - Сохранить результат расчета.

>[!NOTE]
>Результаты расчета сохраняются в формате CSV, разделитель - точка с запятой.
>Результаты сохраняются в табличном виде.

## Вкладка "Таблицы"
<img width="1762" height="1030" alt="image" src="https://github.com/user-attachments/assets/50af5d8d-babd-4091-a415-0bc934f13a37" />

На вкладке располагается четыре таблицы.

В первой таблице приводятся следующие данные:
- Порядковый номер месяца;
- Календарный номер месяца;
- Расход притока;
- Расход ГЭС;
- Расход холостого сброса;
- Отметка верхнего бьефа;
- Отметка нижнего бьефа;
- Напор турбин;
- Мощность ГЭС;
- Величина избыточного объема.

Во второй - обеспеченности:
- Бытового стока;
- Расхода ГЭС;
- Напора ГЭС;
- Среднесуточных мощностей.

В третьей - дефициты по заданным расходам, относительно гарантированных.

В четвертой - значения мощностей контрольного месяца.

>[!NOTE]
>Расходы ГЭС, меньше гарантированного даются на фоне цвета "Коралл".
>Отрицательные расходы ГЭС даются на фоне цвета "Красный".
